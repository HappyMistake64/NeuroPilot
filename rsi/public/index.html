ChatGPT přes Codex v cloudu

Pokud je Codex na této VM přihlášený přes ChatGPT, načti jeho modely a vyber připojení pro RSI. Zadání a upravovaný kód se odesílají OpenAI. Samotné přihlášení ještě nepotvrzuje odpověď modelu.

Pro nové přihlášení spusť v terminálu python -m rsi codex-login. Odkaz a jednorázový kód z terminálu můžeš potvrdit na telefonu; pak zde znovu načti modely.

Dokončit přihlášení v ChatGPT

Přihlášení dokonči v prohlížeči na stejném počítači, kde běží NeuroPilot. Pro cloudovou VM použij bezpečný import registrace podle OPENAI_README.md. Pro připojení přes Codex použij výběr modelu výše.

Test spojení ověří skutečnou odpověď modelu. Experimenty dále vyžadují funkční izolaci kódu. Tokenový rozpočet u ChatGPT hlídáme účetně; jeden dotaz jej může překročit. Limity předplatného a kreditů nastav v ChatGPT Settings → Usage. API klíč se nepoužívá.
